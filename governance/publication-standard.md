# Publication Standard — Indonesia Open Justice Observatory (IOJO)

## 1. Release Requirements (GitHub, Kaggle, GitHub Pages)
Every public dataset or report release must include:
1. Dataset description and plain-language summary.
2. Complete data dictionary (`schemas/data_dictionary.csv`).
3. Explicit source attribution and clickable official URLs.
4. License assessment (separating IOJO code/metadata license from official source terms).
5. Provenance log and SHA-256 checksums.
6. Documented methodology, missingness report, and limitations.
7. Version tag and last-updated date.

## 2. Pre-Release Gate
No `UNVERIFIED` record may be presented as established fact. Source documents (e.g., full judgment PDFs) are **not** redistributed unless expressly permitted by the issuing authority.
